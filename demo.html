0 Address format Examples Explanation
1 Zip code + City NaN This format is used, e.g., in Sweden, Norway, Finland, Denmark, Germany, and Estonia.
2 City + State/Region + Zip code NaN This format is used, e.g., in the USA, Canada, and Australia.
3 City + Zip code (two rows) NaN This format is used e.g. in the USA, Canada, and Australia.
4 City/Province + Zip code NaN This format is used e.g. in China.
5 General NaN This format is intended for countries that do not have a unique address format, e.g., no specific field for zip code. Here you can enter any optional text on all rows, except from the last row which is reserved for the mailing address. However, this is not displayed in the address that is printed.
